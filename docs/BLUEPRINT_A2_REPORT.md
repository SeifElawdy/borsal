## Gate semantics and clarification distinction

The helper reads only authoritative structured product.closure and product.attachments. It never scans product names, silhouette, description or concept text to invent mandatory requirements. Closure description is used only to name an obligation, not infer one.

| Authoritative case | Behavior |
|---|---|
| UNKNOWN with no requirements / mandatory flag | ALLOW; model must echo UNKNOWN. Not unsupported, not automatically NONE. |
| Missing or nonmandatory ambiguous closure metadata | ALLOW with a visible ambiguity warning; no identity rewrite. |
| Explicit NONE, ZIPPER, BUTTON or SNAP | ALLOW the existing representation; exact echo and matching hardware/INSTALL checks remain. These are reference checks, not validated closure function. |
| Explicit VELCRO, DRAWSTRING, other unsupported closure kind | BLOCK with exact named incompatibility before any hold. |
| Explicit mandatory UNKNOWN, contradictory MULTIPLE requirements, malformed explicit requirements slot | BLOCK requiring clarification; never silently dispatch an unverifiable mandatory interpretation. |
| Nonempty authoritative attachment requirement without a structured mapping | BLOCK naming that exact unstructured requirement; no prose guessing. |

This distinguishes **nonmandatory metadata ambiguity** (warn/allow) from **an explicit mandatory obligation that cannot be safely interpreted** (clarify/block). The gate and expander share the same vocabulary function. All function/closure/context data is read-only; no closure/function is reworded or substituted.

An open construction is **optional only if it plausibly preserves the approved function, silhouette and requirements**. UNKNOWN does not force open. The prompt requires an honest limitation when meaningful construction is outside the vocabulary, rather than arbitrary shapes. Such an incomplete response is not accepted as a completed design. Local reference/geometry checks cannot prove semantic usefulness or physical function; human review remains necessary.
