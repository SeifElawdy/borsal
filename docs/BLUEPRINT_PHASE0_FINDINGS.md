## Existing contracts (source of truth)

`src/services/productEngineering.js:schema` is strict `borsal.engineering-plan/0.1`. Required: schemaVersion, name, function, closure, components (1–12), operations (0–30), changes (0–6), unresolved (0–8). Materials default to [] via the existing candidate schema. Each component requires name, purpose, quantity (integer 1–20), shape and allowanceCm >=0; role, grainDirectionDeg [0,180), grainToleranceDeg [0,90], allowedRotationsDeg (1–16 finite numbers) are optional. Dimensions are finite positive cm. Closure enums: NONE, VELCRO, DRAWSTRING, ZIPPER, SNAP, BUTTON, BUCKLE, TOGGLE, HOOK, TIE, UNKNOWN.

Shapes: RECT and ELLIPSE with width,height; POLYGON requires 3–64 explicit vertex tuples. **No compact POLYGON parameterization exists**, so Blueprint excludes it. RECT stitching contour is [0,0]→[w,0]→[w,h]→[0,h], counterclockwise in mathematical coordinates; zero-based edges follow this order. ELLIPSE uses 24 counterclockwise chords, starting at its rightmost point. Coordinates are component-local stitching coordinates. The compiler applies explicit per-component allowanceCm by existing UNIFORM_CONVEX_MITER policy; Blueprint must supply it, not infer it. Roles describe purpose; they do not implement semantic product construction.

Exact operation fields:

* SEAM: sides (exactly two), each {piece,copy,edges,direction:FORWARD|REVERSE}, thread, instruction. Copies are 1-based, edges zero-based. Directed edge chains must be connected; unequal seam lengths remain unverified rather than proving easing.
* ATTACH: from,to ({piece,copy,point}), thread,instruction. Point anchors must be inside the referenced stitching contour.
* INSTALL: material,anchors ([{piece,copy,point}]),instruction. This validates references/anchors, not functional hardware installation.
* FOLD: piece,method (HEM|BOX|PLEAT),from,to,allowance,instruction. Applies to **all copies of that pattern**. Blueprint initially restricts this to explicit HEM axes, not simulated weaving/pleating mechanics.
* FINISH: piece,edges,method:OVERCAST,thread,instruction. Applies to all copies. It does not connect separate components.
* LAYER: layers (2–6 point references),thread,instruction. Existing compiler turns adjacent layers into ATTACH relationships; repeated identical copy references are invalid.

Material entries: name,requirement, optional quantity {value>0,unit:cm|cm2|piece} or threadEstimate {method:ALL_STITCHING_PERIMETERS,multiplier>0,tailCm>=0}. Requirement is the existing strict material union in `experiments/design-language/schema.js` (THREAD, ZIPPER, BUTTON, HARDWARE and other existing types). Thread must reference THREAD; installation must reference a declared material. These are REQUIRED specifications, never available stock. Blueprint restricts materials to explicit thread/hardware requirements and exactly one demand calculation.

The complete existing material union has required `type` and strict `specs`: WOVEN_FABRIC {fiber:COTTON|POLYESTER|BLEND,weave:PLAIN|TWILL|SATIN,weightGsm>0}; LINING_FABRIC {fiber,weightGsm>0}; WEBBING {fiber,widthCm>0}; ZIPPER {lengthCm>0,toothType:COIL|METAL,endType:CLOSED|OPEN}; THREAD {fiber,tex>0}; BUTTON {diameterCm>0,material:METAL|RESIN|WOOD}; HARDWARE {kind:D_RING|SWIVEL_HOOK|MAGNETIC_SNAP|TURN_LOCK|RIVET|BAG_FOOT,finish:BRASS|NICKEL|BLACK,sizeCm>0}; INTERFACING {weightGsm>0,bond:FUSIBLE|SEW_IN}. All numbers are finite. Engineering text uses trimmed nonempty strings of at most 500 characters; reused candidate SEAM/ATTACH/INSTALL and material names use its nonempty trimmed text up to 2,000. Point tuples contain exactly two finite numbers. Existing INSTALL has at least one anchor; SEAM exactly two sides and at least one edge per side; FINISH at least one edge. Existing geometry validation, not the shape Zod alone, decides contour/axis/anchor validity. The Blueprint adapter rejects field-surrounding whitespace instead of silently inheriting trimming as a transport repair.

## Restrictions chosen from these findings

RECT/ELLIPSE only; explicit cm stitching dimensions and allowance; typed local references; edge-index/fraction/inward-inset anchors expand into existing point references. FOLD/FINISH require explicit ALL_COPIES scope, because existing operations cannot target one copy. Unsupported single-copy folds, elastic/gathering/weaving, functional closure verification and free-prose mandatory attachment semantics remain blockers. Do not add compiler capabilities.
